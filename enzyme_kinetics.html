Selected starting [S]

Each curve on the product plot is one experiment at a fixed starting [S]. Product forms in a straight line at first, and that slope is v₀, one point on the M-M plot. As substrate runs out the curve bends, so rates are measured early.

Each run adds one point, using the slope over this window. Try [S] values below and above Km, then widen the window and watch the points fall as substrate runs out.
